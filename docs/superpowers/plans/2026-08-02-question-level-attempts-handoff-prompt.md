## D. 参考: この実装で解決しようとしている問題（依頼先に背景を口頭で説明するとき用）

現状、夜間バッチのLLMは学習結果PDFを**十分に深く読めている**。
2026-08-01 は225問、2026-07-31 は431問を、単元別正答率・設問番号・所要時間まで読んでいる。

問題は出力先が「その日の散文レポート1枚」しかないこと。
`_archive/` に29件の原本があるのに、`subjects/` 配下には英語2科目しか存在せず、
化学基礎・地理・公共・情報・古文・数学C の記録はどこにも残っていない。

実際、アーカイブ済みPDF 18件を機械的に解析したところ
**656試行・ユニーク設問548・複数回解いた設問54** が復元でき、
こういう履歴が取り出せた。

```
推量の助動詞|006   ○→✕→✕→✕→○→○
補助動詞|009       ✕→○→✕     （65秒 → 8秒 → 15秒）
```

2026-07-31 のレポートはこれを「助動詞49/64」の一行に潰していた。
`補助動詞|009` が「一度できたのにまた落ちた＝定着していない」ことは、
現在どこにも残っていない。

この実装は、その失われている事実を追記専用のJSONLに残し、
単元ごとの定着状態をWebで根拠付きに見られるようにする。
